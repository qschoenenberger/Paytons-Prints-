# Payton's Prints

Custom pen-and-ink illustration & print shop — brand, marketing, and website assets.

## What's here

- [`Marketing/`](Marketing/README.md) — the 4x6 two-sided marketing card: editable design-canvas source and print-ready PDFs.
- [`logo/`](logo/) — logo and business card artwork, plus print-ready exports.
- [`qr-code/`](qr-code/) — QR codes linking to the online shop (PNG/SVG/PDF, including transparent variants).
- [`website/website-work-log.md`](website/website-work-log.md) — running log of work on the live Squarespace storefront (there's no local website codebase; the site is edited directly on Squarespace).

See [`CLAUDE.md`](CLAUDE.md) for more detail on how these pieces fit together.
